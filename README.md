# Raptor
Native Objective-C/UIKit YouTube client experiment for iPad 3 (iPad3,1), iOS 9.3.5, ARMv7.

Target: iOS 9.0, armv7, UIKit, NSURLSession and legacy UIWebView.
Current milestone: native UIKit shell, Innertube search request, result parsing, thumbnail loading and video embed view.
Playback on iOS 9 is not yet verified. No account required. No package has been installed.
Build with Theos and an iPhoneOS SDK, then run make package.
