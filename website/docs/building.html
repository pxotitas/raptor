Building Raptor.

Raptor targets ARMv7 devices running iOS 9.0 or later. The primary test device is an iPad 3 on iOS 9.3.5.

Requirements

  • Linux x86_64 or macOS build host.
  • Theos build system and an iOS device SDK.
  • Clang, GNU Make, Perl, ldid, Git and XZ utilities.

Install Theos on Arch Linux

sudo pacman -S --needed base-devel bash curl git perl xz
git clone --recursive https://github.com/theos/theos.git ~/theos
export THEOS="$HOME/theos"

Install the Linux iOS toolchain and an iOS device SDK under $THEOS/sdks. The Theos SDK repository provides patched SDKs. The Raptor target currently uses iOS 9.3.

Build

cd raptor
make clean package FINALPACKAGE=1

The package is written to packages/ as a Debian package for jailbroken iOS devices (iphoneos-arm).

Legacy ARMv7 notes

The Makefile uses -marm to avoid a branch relocation issue in the legacy ARMv7 linker. Use an iOS device SDK, not an iOS Simulator SDK. Its system-library stubs must include ARMv7 exports for the device runtime.

The current development machine keeps legacy toolchain runtime libraries under ~/theos/legacy-libs. If Clang needs them, add that directory to LD_LIBRARY_PATH when invoking Make.

Playback testing

The iPad 3's A5X hardware is intended to use H.264/AVC video and AAC audio. The app must receive a compatible stream from YouTube's player; a browser quality preference alone cannot guarantee a codec. Playback and stream selection still need to be verified on the physical device.
