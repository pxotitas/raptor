Building Raptor

The project targets iOS 9.0 and ARMv7. The primary test device is an iPad 3 running iOS 9.3.5.

Requirements

  • Linux x86_64 or macOS build host.
  • Theos and its iOS cross-toolchain.
  • An iOS SDK installed under $THEOS/sdks.
  • GNU Make, Clang, ldid and dpkg-deb.

Install Theos on Arch Linux

sudo pacman -S --needed base-devel bash curl git perl fakeroot ldid dpkg xz
git clone --recursive https://github.com/theos/theos.git ~/theos
export THEOS="$HOME/theos"

The official Theos Linux installer can also install the toolchain and SDK. See Theos installation instructions.

Build

cd raptor
make clean package

The Linux toolchain is installed separately from the project. On the current development machine, legacy runtime libraries are kept under ~/theos/legacy-libs rather than installed system-wide. The iOS 9.3 SDK is used for the ARMv7 target. The current linker still needs a device-SDK stub correction before the package can be considered complete.

Playback notes

The A5X hardware is intended to use H.264/AVC video and AAC audio. The app must receive a compatible stream from YouTube's player; the browser's quality preference alone cannot guarantee a codec. Test playback on the iPad before treating codec support as complete.
